ℹ️ Detail Relasi: Menampilkan Seluruh Tabel

Klik kartu tabel di atas untuk fokus melihat relasi, constraint unik, dan indeks pencarian.

1. Masalah Duplikasi Siswa di Kunjungan yang Sama (Integritas Data Fatal)

Kekurangan: Sebelumnya, tabel detail_kunjungan belum memiliki constraint unik. Jika form di-submit 2 kali atau scanner barcode membaca dua kali, 1 siswa akan terinput 2 kali di berita acara yang sama.
Perbaikan: Ditambahkan UNIQUE KEY uq_kunjungan_anggota (id_ba, id_anggota). Database akan otomatis menolak duplikasi data siswa di kunjungan yang sama.

2. Kaidah Berita Acara Pemerintahan Hanya 1 Pihak

Kekurangan: Berita Acara di instansi dinas pemerintah adalah dokumen serah terima kegiatan antar dua belah pihak. Sebelumnya hanya ada data pustakawan saja.
Perbaikan: Ditambahkan kolom legalitas: nama_perwakilan_sekolah, nip_perwakilan_sekolah, waktu_mulai, dan waktu_selesai.

3. Kolom Master Anggota Kurang untuk Laporan Tahunan

Kekurangan: Perpustakaan daerah wajib melaporkan demografi pembaca (pria/wanita), status keaktifan siswa (apakah sudah lulus/pindah), dan nomor kartu anggota.
Perbaikan: Ditambahkan nomor_anggota (Unique), jenis_kelamin ENUM('L','P'), dan status_anggota ENUM('aktif','lulus','pindah').

4. Ketiadaan Indexing (Sesuai Rumusan Masalah BAB I: Lambat Mencari Data)

Kekurangan: Di BAB I skripsi ditegaskan bahwa pustakawan sering lambat mencari nama siswa dan sekolah.
Perbaikan: Dibuat index eksplisit (INDEX idx_nama_anggota, INDEX idx_nama_sekolah, INDEX idx_tgl_kunjungan) sehingga pencarian query SQL menggunakan B-Tree yang sangat cepat (O(log n)).

5. Kebijakan Penghapusan Referential (`ON DELETE RESTRICT`)

Kekurangan: Jika operator tidak sengaja menghapus sekolah SDN 1 Gunung Tiga, seluruh riwayat berita acara dan presensi tahunan bisa ikut terhapus.
Perbaikan: Foreign key ke master penting menggunakan ON DELETE RESTRICT, sehingga sistem menolak penghapusan sekolah jika sekolah tersebut sudah memiliki riwayat kunjungan.

-- 1. TABEL SEKOLAH
CREATE TABLE sekolah (
    id_sekolah BIGINT UNSIGNED AUTO_INCREMENT PRIMARY KEY,
    npsn VARCHAR(20) UNIQUE NULL,
    nama_sekolah VARCHAR(100) NOT NULL,
    nama_kepsek VARCHAR(100) NOT NULL,
    alamat TEXT NOT NULL,
    kecamatan VARCHAR(50) NOT NULL DEFAULT 'Lampung Timur',
    kontak_sekolah VARCHAR(25) NULL,
    created_at TIMESTAMP NULL DEFAULT CURRENT_TIMESTAMP,
    updated_at TIMESTAMP NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    INDEX idx_nama_sekolah (nama_sekolah)
);

-- 2. TABEL PUSTAKAWAN
CREATE TABLE pustakawan (
    id_pustakawan BIGINT UNSIGNED AUTO_INCREMENT PRIMARY KEY,
    nip VARCHAR(30) UNIQUE NOT NULL,
    nama VARCHAR(100) NOT NULL,
    jabatan VARCHAR(50) DEFAULT 'Petugas Layanan Keliling',
    no_telp VARCHAR(20) NULL,
    created_at TIMESTAMP NULL DEFAULT CURRENT_TIMESTAMP,
    updated_at TIMESTAMP NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    INDEX idx_nama_pustakawan (nama)
);

-- 3. TABEL USERS (1:1 DENGAN PUSTAKAWAN)
CREATE TABLE users (
    id_user BIGINT UNSIGNED AUTO_INCREMENT PRIMARY KEY,
    id_pustakawan BIGINT UNSIGNED NULL UNIQUE,
    username VARCHAR(50) UNIQUE NOT NULL,
    password VARCHAR(255) NOT NULL,
    role ENUM('admin', 'pustakawan') DEFAULT 'pustakawan',
    status_aktif BOOLEAN DEFAULT TRUE,
    created_at TIMESTAMP NULL DEFAULT CURRENT_TIMESTAMP,
    updated_at TIMESTAMP NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    CONSTRAINT fk_users_pustakawan FOREIGN KEY (id_pustakawan) 
        REFERENCES pustakawan(id_pustakawan) ON DELETE RESTRICT ON UPDATE CASCADE
);

-- 4. TABEL ANGGOTA (SISWA)
CREATE TABLE anggota (
    id_anggota BIGINT UNSIGNED AUTO_INCREMENT PRIMARY KEY,
    id_sekolah BIGINT UNSIGNED NOT NULL,
    nomor_anggota VARCHAR(30) UNIQUE NOT NULL,
    nisn VARCHAR(20) NULL,
    nama VARCHAR(100) NOT NULL,
    jenis_kelamin ENUM('L', 'P') NOT NULL,
    kelas VARCHAR(20) NOT NULL,
    alamat TEXT NULL,
    status_anggota ENUM('aktif', 'lulus', 'pindah') DEFAULT 'aktif',
    created_at TIMESTAMP NULL DEFAULT CURRENT_TIMESTAMP,
    updated_at TIMESTAMP NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    CONSTRAINT fk_anggota_sekolah FOREIGN KEY (id_sekolah) 
        REFERENCES sekolah(id_sekolah) ON DELETE RESTRICT ON UPDATE CASCADE,
    INDEX idx_nama_anggota (nama),
    INDEX idx_sekolah_anggota (id_sekolah)
);

-- 5. TABEL BERITA ACARA
CREATE TABLE berita_acara (
    id_ba BIGINT UNSIGNED AUTO_INCREMENT PRIMARY KEY,
    nomor_ba VARCHAR(50) UNIQUE NOT NULL,
    id_sekolah BIGINT UNSIGNED NOT NULL,
    id_pustakawan BIGINT UNSIGNED NOT NULL,
    tgl_kunjungan DATE NOT NULL,
    waktu_mulai TIME NULL,
    waktu_selesai TIME NULL,
    nama_perwakilan_sekolah VARCHAR(100) NOT NULL,
    nip_perwakilan_sekolah VARCHAR(30) NULL,
    catatan TEXT NULL,
    created_at TIMESTAMP NULL DEFAULT CURRENT_TIMESTAMP,
    updated_at TIMESTAMP NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    CONSTRAINT fk_ba_sekolah FOREIGN KEY (id_sekolah) 
        REFERENCES sekolah(id_sekolah) ON DELETE RESTRICT ON UPDATE CASCADE,
    CONSTRAINT fk_ba_pustakawan FOREIGN KEY (id_pustakawan) 
        REFERENCES pustakawan(id_pustakawan) ON DELETE RESTRICT ON UPDATE CASCADE,
    INDEX idx_tgl_kunjungan (tgl_kunjungan)
);

-- 6. TABEL DETAIL KUNJUNGAN
CREATE TABLE detail_kunjungan (
    id_detail BIGINT UNSIGNED AUTO_INCREMENT PRIMARY KEY,
    id_ba BIGINT UNSIGNED NOT NULL,
    id_anggota BIGINT UNSIGNED NOT NULL,
    waktu_hadir TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    CONSTRAINT fk_detail_ba FOREIGN KEY (id_ba) 
        REFERENCES berita_acara(id_ba) ON DELETE CASCADE ON UPDATE CASCADE,
    CONSTRAINT fk_detail_anggota FOREIGN KEY (id_anggota) 
        REFERENCES anggota(id_anggota) ON DELETE RESTRICT ON UPDATE CASCADE,
    UNIQUE KEY uq_kunjungan_anggota (id_ba, id_anggota),
    INDEX idx_detail_ba (id_ba),
    INDEX idx_detail_anggota (id_anggota)
);
