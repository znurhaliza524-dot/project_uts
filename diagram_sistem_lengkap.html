Hak Istimewa Administrator

  • Memiliki kendali penuh untuk menambah, mengubah, dan menghapus master Sekolah.
  • Satu-satunya role yang memiliki hak akses menu Master Data Pustakawan (NIP, Jabatan).
  • Dapat memantau dan mencetak seluruh rekapitulasi data anggota dan kunjungan.

Hak Operasional Petugas

  • Akses melihat & mencari data sekolah (Read-Only; tidak dapat edit/hapus).
  • Dapat melakukan registrasi anggota siswa baru serta mencetak kartu identitas siswa.
  • Membuat Berita Acara kunjungan armada perpustakaan keliling dan mengisi daftar hadir siswa.

    activate View
    View->>View: Tampilkan Loading Spinner pada Modal

    View->>Controller: GET /anggota/cetak-massal (Header: X-Requested-With XMLHttpRequest)
    activate Controller
    Controller->>Model: Anggota::with('sekolah')->orderBy('nama_anggota')->get()
    activate Model
    Model->>DB: SELECT * FROM anggota JOIN sekolah ...
    DB-->>Model: Return Recordset Siswa & Sekolah
    Model-->>Controller: Collection Objek Anggota
    deactivate Model

    Controller-->>View: Return Partial HTML View (_modal_kartu_massal.blade.php)
    deactivate Controller

    View->>View: Inject Partial HTML ke dalam Container Modal

7. Entity Relationship Diagram (ERD)

Struktur 6 tabel dalam database db_perpustakaan_keliling dengan konvensi primary key id_namatabel dan integritas foreign key referensial. 

erDiagram
    SEKOLAH ||--o{ ANGGOTA : "memiliki siswa"
    SEKOLAH ||--o{ BERITA_ACARA : "menerima kunjungan"
    PUSTAKAWAN ||--o{ BERITA_ACARA : "ditugaskan ke"
    BERITA_ACARA ||--|{ DETAIL_KUNJUNGAN : "memuat daftar hadir"
    ANGGOTA ||--o{ DETAIL_KUNJUNGAN : "tercatat hadir di"
    PUSTAKAWAN ||--o| USERS : "opsional tertaut akun"

    SEKOLAH {
        int id_sekolah PK
        string nama_sekolah
        text alamat
        string kecamatan
        string nama_kepsek
        timestamp created_at
        timestamp updated_at
    }

    PUSTAKAWAN {
        int id_pustakawan PK
        string nama
        string nip
        string jabatan
        string no_telp
        timestamp created_at
        timestamp updated_at
    }

    USERS {
        int id PK
        string username
        string password
        string nama_lengkap
        string role "admin atau pustakawan"
        int id_pustakawan FK "Nullable"
        timestamp created_at
        timestamp updated_at
    }

    ANGGOTA {
        int id_anggota PK
        string nomor_anggota "Unique"
        string nisn "Unique"
        string nama_anggota
        string kelas
        string jenis_kelamin "L atau P"
        int id_sekolah FK
        timestamp created_at
        timestamp updated_at
    }

    BERITA_ACARA {
        int id_ba PK
        string nomor_ba "Unique"
        date tgl_kunjungan
        int id_sekolah FK
        int id_pustakawan FK
        text keterangan
        timestamp created_at
        timestamp updated_at
    }

    DETAIL_KUNJUNGAN {
        int id_detail PK
        int id_ba FK
        int id_anggota FK
        boolean hadir
        timestamp created_at
        timestamp updated_at
    }
Nama Tabel Primary Key Foreign Key Relasi Deskripsi & Peran Fungsional
sekolah id_sekolah - Master data sekolah mitra layanan armada di wilayah Kab. Lampung Timur.
pustakawan id_pustakawan - Data petugas perpustakaan keliling (NIP, Jabatan, Kontak). Khusus dikelola Admin.
users id id_pustakawan (opsional) Kredensial login akun sistem dengan RBAC (Role: admin / pustakawan).
anggota id_anggota id_sekolah Data siswa anggota perpustakaan, NISN unik, dan data cetak kartu berukuran standar KTP.
berita_acara id_ba id_sekolah, id_pustakawan Catatan arsip resmi kunjungan armada mobil keliling ke sekolah.
detail_kunjungan id_detail id_ba, id_anggota Tabel penghubung presensi kehadiran setiap anggota siswa pada berita acara terkait.
